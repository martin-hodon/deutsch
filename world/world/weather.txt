# what it makes an outside place (properties.txt); the SEASONS and how likely each weather is in them.
#     WEATHER name : the clause ; property value ; ... ; noun N ; bad   (N: what one likes or not of it -- people.txt
#     TASTE; bad: one is out in it only when it causes the story's trouble -- the rain that wets her book)
#     SEASON Noun : weather {weight} | weather ...
